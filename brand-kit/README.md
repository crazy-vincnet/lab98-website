# Lab98 브랜드 파일 v1.3

## logo/
모든 로고의 글자는 도형(아웃라인)으로 바뀌어 있어요. 서체를 설치하지 않아도 어디서나 똑같이 보여요.

| 폴더 | 내용 |
|---|---|
| symbol/ | 심볼만 (SVG). 앱 아이콘, 프로필 사진, 도장 |
| lockup/ | 심볼 + 워드마크 가로형 (SVG). 웹 헤더, 문서, 명함 |
| png/symbol/ | 심볼 PNG 1024×1024, 투명 배경 |
| png/lockup/ | 가로형 PNG 높이 400px, 투명 배경 |
| favicon/ | 대표 로고 파비콘 16, 32, 48, 180(애플 터치), 512px |

파일 이름 규칙: `lab98-{master|web|ai|faith}-{symbol|lockup}[-inverse]`
- master = 회사 대표 (시그널 레드 점)
- web / ai / faith = 사업부 (블루 / 그린 / 골드 점)
- -inverse = 검정이나 어두운 배경에 쓰는 버전 (흰 블록, 흰 글자)

## figma/
Figma에 끌어다 놓으면 편집 가능한 레이어가 되는 SVG 보드 5개. 자세한 방법은 figma/README.md.

## tokens.css / tokens.json
컬러, 서체, 모서리, 테두리 값. 웹사이트 개발할 때 그대로 가져다 쓸 수 있어요.

## 로고 규칙 요약
- 보호 여백: 점 지름의 2배 이상
- 최소 크기: 심볼 24px (16px 파비콘에서는 블록과 점만 보여요)
- 늘리기, 회전, 임의 색상, 그림자 금지
- 컬러 비율: 흰색 60 · 검정 30 · 콘크리트 8 · 포인트 2
