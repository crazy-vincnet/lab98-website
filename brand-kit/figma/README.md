# Figma로 가져오기

1. Figma에서 새 디자인 파일을 열어요.
2. 이 폴더의 SVG 5개를 캔버스로 한꺼번에 끌어다 놓아요. (또는 메뉴 > File > Place image)
3. 각 SVG가 프레임 하나가 되고, 안의 요소는 편집 가능한 레이어로 들어와요.
   - 로고: 벡터 도형 (글자가 이미 도형으로 바뀌어 있어 서체가 없어도 똑같이 보여요)
   - 이름, 설명, 라벨: 편집 가능한 텍스트 레이어
4. 텍스트 레이어용 서체는 Figma에 기본으로 있는 Google Fonts예요: Archivo, IBM Plex Sans KR, JetBrains Mono (탐색 기록의 손글씨 시안만 Gaegu)
